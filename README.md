# Customer-purchase-analysis
# Customer Purchase Analytics Pipeline 📊

## Overview
Built an ETL pipeline to process customer purchases and generate age-group-based spending insights.

---

## Features
- CSV ingestion
- Dataset joins
- Data transformation
- Aggregation
- Filtering
- Business analytics

---

## Architecture
CSV → Python ETL → Aggregation → Output CSV

---

## Tech Stack
- Python
- Pandas
- SQL

---

## Business Use Case
Helps businesses identify:
- High spending customer groups
- Purchase behavior
- Revenue distribution

---

## How to Run

```bash
python etl/pipeline.py
```

---

## Output
- Aggregated spending by age group
- Filtered high-value transactions
